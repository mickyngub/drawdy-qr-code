# Changelog

## 1.0.0

First public release

- make a QR code for a link, text, Wi-Fi login, email, phone number, SMS, contact card or map location
- see the exact payload the code holds, with Wi-Fi, email and vCard escaping done for you
- pick error correction L, M, Q or H, a quiet zone of 2 to 4 modules, and square, dot or rounded modules
- set the size, code colour and background, with a contrast warning, and an optional caption
- place it as shapes you can recolour or as a PNG image
- select a code you made, edit it and update it in place
- options are remembered between sessions
