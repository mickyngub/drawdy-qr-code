## 1.0.0

First public release

- make a QR code for a link, text, Wi-Fi login, email, phone number, SMS, contact card or map location
- see the exact payload the code holds, with Wi-Fi, email and vCard escaping done for you
- pick error correction L, M, Q or H, a quiet zone of 2 to 4 modules, and square, dot or rounded modules
- set the size, code colour and background, with a contrast warning, and an optional caption
- put the Drawdy logo or your own picture in the middle; upload a PNG, JPG, WebP, GIF or SVG, or drop it on the preview, and error correction stays at H so the code still scans
- start from six presets (Classic, Drawdy, Navy dots, Mint, Cream, Violet) that set the style and colours in one click, each previewed with your picture
- place it as shapes you can recolour or as a PNG image, in one undo step, beside existing content and clear of the panel, selected
- select a code you made, edit it and update it where it is now, keeping its group, layer, frame, lock and opacity; Place as new makes a copy
- links like example.com:8080 and localhost:3000 get https://, while mailto:, tel:, geo:, WIFI: and other bare schemes are kept
- PNG captions in Thai and other scripts without spaces wrap inside the card
- the Wi-Fi password is hidden as you type, with a Show toggle
- ⌘Z and Ctrl+Z undo on the board from the panel, Escape in a field leaves the field, and the panel follows the board theme while open
- options are remembered between sessions; storage and board permissions are asked when the panel first opens
- a full board, a denied permission or a board that doesn't answer gets a clear message instead of a stuck button
